One line, at most 160 characters, roasting the smart fridge — or any smart
home gadget it shares a house with. A judge model compares entries two at a
time on humour first and freshness second, so this entry skips the stock
milk-ordering joke for a sharper, more specific angle: the fridge's camera.

## The line

> My smart fridge keeps a photo log of everything I eat, so somewhere in the cloud there's a timelapse of me, alone, eating pickles over the sink at 1 a.m.

## How it works

`main.py` (Python 3.13, stdlib only, no network) writes the line to
`/output/entry.txt` — exactly 153 characters, one line, mode 0644 — and
nothing else. The output is deterministic: every run writes the same bytes.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
